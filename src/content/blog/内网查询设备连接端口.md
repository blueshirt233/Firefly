# 内网查询具体的端口

内网查询具体的端口，先在核心上arp和mac-address查询一下，
display一下先 
```
display arp | incloud xxx.xxx.xxx.xxx 
display mac-address | incoud xxxx-xxxx-xxxx-xxxx 
```
然后会输出端口，可能是具体的端口，也可能是虚拟的聚合端口 具体的端口就直接查询邻居设备是哪一台
```
dis lldp neighbor-information list 
```
虚拟的聚合端口就先查询聚合了哪些端口
```
dis link-aggregation verbose Bridge-Aggregation x
```
然后根据具体端口查询邻居设备 到邻居设备这边可以先
```
display mac-address
```
看一下具体的端口，如果网络层级小也可以直接看邻居设备直接输出结果

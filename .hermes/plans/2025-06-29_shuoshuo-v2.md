# 说说 V2 — 合并列表页（取消详情页）+ UI优化方案

> **目标:** 取消详情页，所有内容（Markdown正文、图片Fancybox、视频播放）合并到列表页；标签移至右下角；统一使用博客字体体系

**影响文件:** 删除 1 个，修改 3 个

---

## 架构变化

| 变更 | 旧 | 新 |
|------|----|----|
| 详情页 | `/shuoshuo/[...slug].astro` | **删除** |
| 列表页 | 仅卡片头部信息 | **全文渲染**：Markdown正文 + 图片灯箱 + 视频 |
| 图片 | 点击跳转详情页 | 点击打开 **Fancybox 灯箱**（与相册一致） |
| 视频 | 详情页独立显示 | **列表页内嵌**播放 |
| 标签位置 | 卡片底部横排 | **右下角胶囊** 风格 |
| 评论 | 每条说说独立评论 | **移除**（列表页不适合逐条评论） |
| 字体 | `text-sm` 硬编码 | 博客字体变量 + `text-base` |

## Task 2: 重写列表页 `src/pages/shuoshuo/index.astro`

### 核心变化

1. **全文渲染**: 每条说说使用 `render(entry)` 渲染 Markdown 正文
2. **图片灯箱**: 添加 `FancyboxManager`，图片用 `data-fancybox` 标记
3. **视频内嵌**: `Fragment set:html={renderVideoHtml(...)}` 直接播放
4. **标签右下角**: 放在卡片右下角，胶囊按钮风格，`absolute bottom-4 right-4`
5. **字体**: 正文用 `text-base` + `font-family: var(--font-body, var(--font-inter))`
6. **移除**: 详情页链接、评论系统

### 完整模板

```astro
---
import { getCollection, render } from "astro:content"
import { Icon } from "astro-icon/components"
import FancyboxManager from "@/components/features/FancyboxManager.astro"
import MainGridLayout from "@/layouts/MainGridLayout.astro"
import type { MarkdownHeading } from "astro"
import { profileConfig } from "@/config"
import I18nKey from "@/i18n/i18nKey"
import { i18n } from "@/i18n/translation"
import { renderVideoHtml } from "@/utils/shuoshuo-utils"

const headings: MarkdownHeading[] = []
const allItems = await getCollection("shuoshuo", ({ data }) => {
  return import.meta.env.PROD ? data.draft !== true : true
})
const sorted = allItems.sort((a, b) => {
  if (a.data.pinned && !b.data.pinned) return -1
  if (!a.data.pinned && b.data.pinned) return 1
  return new Date(b.data.published).getTime() - new Date(a.data.published).getTime()
})

// 预渲染每条说说的 Markdown 内容
const rendered = await Promise.all(
  sorted.map(async (item) => {
    const { Content } = await render(item)
    return { ...item, Content }
  })
)
---

<MainGridLayout title={i18n(I18nKey.shuoshuo)} description={i18n(I18nKey.shuoshuoDescription)} headings={headings}>
  <div class="flex flex-col gap-4">
    <p class="text-sm text-(--content-meta)">共 {rendered.length} 条说说</p>
    {rendered.length === 0 ? (
      <div class="card-base rounded-(--radius-large) p-12 text-center text-(--content-meta)">
        <Icon is:inline name="material-symbols:chat-bubble-outline-rounded" class="text-5xl mb-3 opacity-40" />
        <p>{i18n(I18nKey.shuoshuoNoContent)}</p>
      </div>
    ) : (
      rendered.map((item) => {
        const images: string[] = item.data.images || []
        const videos = item.data.videos || []
        const hasImages = images.length > 0
        const hasVideos = videos.length > 0
        
        return (
          <div class="card-base rounded-(--radius-large) p-5 md:p-6 relative group">
            <!-- ── 头部：头像 + 时间 + 置顶 ── -->
            <div class="flex items-center gap-3 mb-3">
              <div class="w-10 h-10 rounded-full bg-(--primary) flex items-center justify-center text-white font-bold shrink-0">
                F
              </div>
              <div>
                <div class="font-bold text-sm text-black/75 dark:text-white/75">
                  {profileConfig.name}
                </div>
                <div class="text-xs text-(--content-meta)">
                  {new Date(item.data.published).toLocaleDateString("zh-CN", {
                    year: "numeric", month: "long", day: "numeric",
                    hour: "2-digit", minute: "2-digit",
                  })}
                </div>
              </div>
              <div class="ml-auto">
                {item.data.pinned && (
                  <span class="text-xs px-2 py-0.5 rounded-full bg-(--primary)/10 text-(--primary) font-medium">
                    {i18n(I18nKey.pinned)}
                  </span>
                )}
              </div>
            </div>

            <!-- ── 正文区域 (加粗、链接等 Markdown 渲染) ── -->
            <div 
              class="text-base text-black/80 dark:text-white/80 leading-relaxed mb-4 markdown-content shuoshuo-body"
              style="font-family: var(--font-body, var(--font-inter), sans-serif);"
            >
              <item.Content />
            </div>

            <!-- ── 图片九宫格 + Fancybox 灯箱 ── -->
            {hasImages && (
              <div class="grid gap-1 rounded-xl overflow-hidden mb-4"
                   style={`grid-template-columns: repeat(${Math.min(images.length, 3)}, 1fr)`}>
                {images.slice(0, 9).map((img, idx) => {
                  const isOverflow = idx === 8 && images.length > 9
                  return (
                    <a href={img}
                       data-fancybox={`shuoshuo-${item.id}`}
                       class="relative block aspect-square overflow-hidden bg-black/5 dark:bg-white/5">
                      <img src={img} alt="" loading="lazy" decoding="async"
                           class="w-full h-full object-cover hover:scale-105 transition-transform duration-300" />
                      {isOverflow && (
                        <div class="absolute inset-0 bg-black/50 flex items-center justify-center">
                          <span class="text-white text-xl font-bold">+{images.length - 9}</span>
                        </div>
                      )}
                    </a>
                  )
                })}
              </div>
            )}

            <!-- ── 视频内嵌播放 ── -->
            {hasVideos && (
              <div class="flex flex-col gap-3 mb-4">
                {videos.map((video: any) => (
                  <div class="rounded-xl overflow-hidden bg-black">
                    <Fragment set:html={renderVideoHtml({
                      type: video.type as "bilibili" | "youtube" | "direct",
                      bvid: video.bvid,
                      youtubeId: video.youtubeId,
                      src: video.src,
                      title: video.title,
                    })} />
                  </div>
                ))}
              </div>
            )}

            <!-- ── 标签（右下角胶囊） ── -->
            {item.data.tags && item.data.tags.length > 0 && (
              <div class="flex flex-wrap justify-end gap-1.5 mt-2">
                {item.data.tags.map((tag: string) => (
                  <a href={`/tags/${tag}/`}
                     class="text-xs px-2.5 py-1 rounded-full 
                            bg-(--enter-btn-bg) text-(--primary)
                            hover:bg-(--primary)/20 hover:scale-105
                            active:scale-95 transition-all duration-200
                            font-medium">
                    #{tag}
                  </a>
                ))}
              </div>
            )}
          </div>
        )
      })
    )}
  </div>

  <FancyboxManager />
</MainGridLayout>

<style is:global>
  /* 说说正文区域样式 - 使用博客字体体系 */
  .shuoshuo-body {
    font-family: var(--font-body, var(--font-inter), sans-serif);
    font-size: 1rem; /* ~16px, 比文章正文稍大 */
    line-height: 1.75;
  }
  .shuoshuo-body p {
    margin-bottom: 0.75em;
  }
  .shuoshuo-body a {
    color: var(--primary);
    text-decoration: underline;
  }
  .shuoshuo-body img {
    display: none; /* 正文内图片由上方九宫格统一管理 */
  }
  .shuoshuo-body code {
    font-family: var(--font-jetbrains-mono), monospace;
    font-size: 0.9em;
    background: var(--inline-code-bg);
    color: var(--inline-code-color);
    padding: 0.1em 0.3em;
    border-radius: 0.25em;
  }
</style>
```
